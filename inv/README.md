# Invitaciones digitales Akiko

Dos ejemplos listos para personalizar: boda (`valeria-andres`) y cumpleaños (`sofia-30`). Cada invitación comparte la plantilla en `_plantilla/` y toma el contenido de su propio `datos.js`.

## Abrir y publicar

Sube la carpeta `inv` completa a un sitio web estático y comparte el enlace de la carpeta de cada evento. También puedes abrir `index.html` directamente para ver el diseño; las confirmaciones de demostración se simulan localmente. Las tipografías se cargan desde Google Fonts cuando hay conexión.

## Carpetas

- `_plantilla/`: estilos, efectos y lógica compartida; no requiere instalación ni compilación.
- `valeria-andres/`: boda de ejemplo, pases personalizados y carpeta para fotografías.
- `sofia-30/`: cumpleaños de ejemplo con confirmación mediante hoja de cálculo.
- `panel/`: panel para anfitriones de eventos con pases.
- `apps-script/`: receptor opcional de respuestas en Google Sheets.

Para editar un evento, cambia su `datos.js`. Consulta [NUEVA-INVITACION.md](NUEVA-INVITACION.md) para crear uno y [las instrucciones de Apps Script](apps-script/INSTRUCCIONES.md) para guardar respuestas reales.
